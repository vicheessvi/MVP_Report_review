# Контроль отчётов PPTX

Скачайте файл [«Контроль отчётов.html»](./Контроль%20отчётов.html) и откройте его с диска в актуальном браузере. Для запуска достаточно этого файла.

1. Загрузите текущий отчёт в формате PPTX и укажите дату отчёта.
2. При необходимости загрузите прошлый отчёт.
3. Нажмите **«Проверить отчёт»**. Замечания содержат номер слайда и фрагмент текста. Их можно отфильтровать и выгрузить в CSV.

Инструмент отмечает даты строго раньше даты отчёта как критичные. Отдельно показывает некорректные даты и пункты, которые были выполнены в прошлом отчёте и снова появились в текущем. Он обрабатывает редактируемый текст слайдов и таблиц. Текст на скриншотах, в диаграммах, SmartArt и заметках проверяется вручную.

Презентации обрабатываются локально в браузере. Политика безопасности HTML блокирует сетевые запросы.

## Сборка из исходников

Чтобы пересобрать автономный HTML после изменения файлов в каталоге src, выполните команду из корня репозитория.

~~~sh
node build-offline.mjs
~~~
